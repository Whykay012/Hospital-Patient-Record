# Healthcare Dataset — Data Inventory

| Table | Description | Expected Grain |
|---|---|---|
| patients | Contains patient-level demographic and identifying information | One row per patient |
| encounters | Contains healthcare visit/encounter records | One row per encounter |
| procedures | Contains procedures associated with patient encounters | One row per procedure |
| payers | Contains payer/insurance information | One row per payer |
| organizations | Contains healthcare organization/facility information | One row per organization |
